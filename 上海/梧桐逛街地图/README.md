# 梧桐逛街地图

独立新网站，依据用户给出的13篇不同上海逛街笔记制作。第一篇误入笔记已忽略，同一URL重复出现只记一次；跨笔记同店保留全部来源。

本地入口为 dist/index.html，建议通过 python -m http.server 8765 --directory dist 打开以获得完整地图体验。

五条路线：静安寺—南京西路；安福—五原—武康；巨鹿—富民—东湖；淮海中路向东；乌南—建国西—永嘉—汾阳。核心线分别约3.2/2.3/1.3/1.3/1.9公里，时间仅纯步行参考，不含逛店、等候与加选。

共94条店铺／地点线索，含未识别描述；不是94家已验证营业门店。13个同名地图POI（高德11、百度2），55个门牌、同楼或候选参考点，26条未定位。默认展示全部路线和全部状态，待核、过期记录保留显著标识；可按核心和状态筛选。搜索跨路线与状态检索。

数据：research.json与dist/data.js；原始核查文件research-*.json；重建脚本scripts/build-data.py。地理编码使用Esri公开地址API，坐标为WGS84；高德GCJ02数据先转换；步行几何使用FOSSGIS公开OSM foot graph。

来源阅读范围与缺口逐篇公开。部分视频仅抽查，尚有店名未识别；位置不明不放猜测图钉。过森日已过原文活动期；The Edit Room、小玉、22 COLLECTION等保留待核，避免把历史快闪、地址差异当作当前确定门店。
