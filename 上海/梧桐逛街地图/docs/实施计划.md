# 梧桐逛街地图 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 制作以12篇笔记为依据的5路线简洁地图网站。
**Architecture:** 纯静态网站，独立数据文件驱动路线、地图与店铺卡片。复用现有Leaflet资源，明确区分门店坐标和街区近似点。
**Tech Stack:** HTML/CSS/JavaScript、Leaflet。
**Spec:** 设计说明.md

## Global Constraints
- 简洁地图＋5条路线，店铺风格概括，保留12篇独立来源，位置不明与过期快闪明确标注。
- 第一篇误入笔记忽略；相同链接重复出现不视为不同笔记。

## Review Focus
- 地图瓦片加载失败：清单仍可读。
- 同名不同分店：分别定位。
- 坐标不明：不伪装精确门店。
- 搜索无结果：显示空状态。
- 手机窄屏：不横向溢出。

### Task 1: 研究与数据
**Files:** research.json、dist/data.js
**Interfaces:** 店铺记录包含name/style/address/locationStatus/sourceIds/routeId；来源包含原文链接、阅读范围、缺口。
- [ ] 逐篇核对正文、图片和可读视频信息，独立核实地址。
- [ ] 按地理位置编排5条建议路线；不明门店保留待核实条目。
- [ ] 运行数据检查：来源ID可解析、路线引用存在、所有精确点均有地址证据。

### Task 2: 地图与交互
**Files:** dist/index.html、dist/app.js、dist/style.css、dist/vendor/
**Interfaces:** data.js导出DATA，app.js读取路线和店铺。
- [ ] 先检查来源、搜索、选择路线、点位弹窗、地图失效和窄屏的预期行为。
- [ ] 实现地图＋侧栏，风格概括、来源链接、高德跳转、5路线筛选和未核实清单。
- [ ] 使用内置浏览器验证以上行为与移动布局。

- [ ] 使用Sites工作流提交源码、打包并发布同一版本。
