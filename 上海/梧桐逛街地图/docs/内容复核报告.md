2. **P1｜整街点进入核心路线｜r1/r3/r5，s05/s25/s33/s35/s70/s72。** 这些点 `broadLocation=true`，仍在 `coreIds` 和 `path`。s25 实际复用了巨鹿路741号而其地址为699-4号；s35 只匹配整条华亭路，却让 r3 从新乐路向西南绕约650米再向东北返回东湖路。当前点位不足以支持这一绕行。先替换可靠同楼锚点；不能替换的保留清单、移出路由节点，并明确路线未覆盖该门牌。OSM步行路线只会准确连到错误/宽泛端点，不能解决端点问题。

3. **P1｜锚点结构未兼容｜s01/s03/s05/s58/s59，apply_anchors()。** south 锚点文件使用 `targetNames`，脚本只读 `matchKeys` 或道路门牌；素舶、TWOI、Fabrique、PSO BRAND、W0311因此未使用已备妥的商场POI。Fabrique退化为石门一路整街点，前两店也采用了较低等级地理编码。显式按稳定店铺ID或目标店名绑定锚点；只把位置升为 approximate，不能借锚点提高营业/身份可信度。对PSO使用商场锚点时须继续保持uncertain。

4. **P2｜疑似冲突地理编码｜s09 TOGGLER，r2。** Esri虽回显华山路847号和100分，但输出 WGS84 `31.203979,121.430726`，位于安福路核心点南约1.2公里；r2却把华山称作北侧加选。锚点研究已记有华山847/849不同位置冲突。建议先取消该点位、保留门牌待地图复核；不要仅凭score=100判断可靠。确认后再决定属于哪侧加选，并与 extension 标记一致。

5. **P2｜地址可定位不等于身份/现址已核｜s13/s27/s29/s25。** Alicia、chelchel、Freja的原研究 confidence=unknown，门牌来自原文且未独立确认；LADYFAFA仅有2022旧址。脚本在套用邻居或建筑锚点后统一把 uncertain 升为 active，使它们离开待核筛选，LADYFAFA更进入核心路线。前端已有“正常收录不代表当前营业”免责声明，但仍应保留这些记录的uncertain状态；位置可信度与门店身份/现址可信度分别处理。

6. **P2｜两篇正文数量需快速对照｜n02/n12。** n02 scope写“正文10店清单”，实际关联9条；n12标题/说明写13家，实际关联12条。这是可重复的计数差异，尚不能仅凭数量认定缺哪家（可能重复或原文计数不同）。对照已读正文和图片清单，补遗漏或在limitations解释差异；不要求继续逐秒研读n07/n09。

7. **P3｜风格描述证据层级不明确｜s22/s48/s70等。** Yearly Plan研究只确认空间、服装风格待核，最终变为“中性长期主义”；CUBIC研究为“舒适优雅都市女装”，最终加“建筑感廓形与克制配色”；miulab研究写古着复古，最终写韩牌买手。原文视频/图片可能支持这些判断，现有本地研究无法独立证实。若来自原笔记，明确写“原文/视频呈现……”；若无对应证据，收敛为已支持的品类，避免把编辑印象写成核实事实。
