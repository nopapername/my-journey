# 上海梧桐逛街地图设计

目标：研读用户提供的12篇上海逛街笔记，生成一个独立、简洁的地图网站。第一篇误入文章忽略；原始列表相同URL只审读一次，不合并不同笔记。

界面：桌面左侧路线与店铺列表、右侧地图；手机上方路线选择、地图与店铺卡片。使用浅底、清晰编号与5条路线配色。店铺弹窗概括风格、地址、来源和核实状态，提供高德搜索或导航。

内容：按实际地理位置划分5条独立动线；跨笔记同店合并来源，不同分店分别记录。服装为主，餐饮、珠宝、杂货为顺路补充。尽量完整收录，无法识别或核实的信息公开列为待补全，禁止编造。

地图：复用现有项目本地Leaflet资源，使用地图瓦片服务；路线折线表达建议顺序。只有经核实的坐标参与精确线路；街段近似点醒目标注，不作为精确导航终点。所有距离和时间注明估算或地图服务计算依据。

数据：独立JSON保存店铺、来源和路线；前端纯静态HTML/CSS/JS，无账户和后台。活动已过原文期限的快闪保留记录，默认排除当前路线。地图加载失败时仍可读完整清单并跳转高德。

验收：12篇来源可追溯；5条路线均可切换；点店可显示风格和来源；手机无横向溢出；未知坐标不会伪装为精确坐标；快闪过期有标注。部署为新的私人Sites网站并交付网址及本地文件。
