## 功能与可用性检查

- 全局搜索明确临时覆盖路线、核心及状态；界面禁用相冲突的筛选控件，并说明清空关键词恢复原筛选。切换路线会清空关键词。
- 待核与过期筛选自动取消核心限制。默认正常收录不包含过森日等过期记录；全局搜索能找到过期记录，并显示提示。
- 同坐标记录共用图钉，弹窗提供逐店切换，所有店铺 ID 均映射到对应图钉；共用参考坐标不被描述成已确认同址。
- 未定位记录不生成图钉，仍保留卡片与来源。当前总计 90 条线索，11 条同名 POI、50 条近似参考、29 条未定位，页面用“记录”表达覆盖数。
- 来源、定位证据和高德搜索链接在卡片或弹窗可达。显示文本经 textContent 写入，外部证据链接限制为 HTTP(S)，新窗口链接带 noopener/noreferrer。
- Leaflet 缺失或初始化失败时，清单、筛选、来源及高德搜索仍能初始化；瓦片错误和超时会显示降级提示。纯静态页面不依赖后端。
- 窄屏样式将控制区、地图、清单、来源按序排列，路线横向滚动，480px 以下卡片单列，地图和列表使用可收缩列。此次按任务要求未启用浏览器；桌面／390px 无横溢和瓦片成功加载属于主代理此前的浏览器验证，不作为本审阅者独立实测结论。

## 非阻塞小问题

**P3｜位置提示不会在后续选择中自动消失。** `dist/app.js:142` 对未定位店铺调用 showNotice；正常的 focusShop 分支以及 render 流程没有清除该提示。因此点未定位条目后再点已定位店铺或切换路线，地图顶部可能仍显示上一条目的“尚无可靠坐标”提示。提示含店名，且不妨碍操作，不阻止交付。后续可把临时选点提示与底图故障提示分别管理，在选中已定位点或改变筛选时清除临时提示。
